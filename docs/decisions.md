# Decision 005

Title:
The Observatory transforms around the visitor.

Decision:
The visitor never navigates between traditional webpages.

Mission Control remains the visitor's home throughout the experience.

As the visitor explores, the observatory itself changes:

- Polaris updates his briefing.
- The telescope rotates.
- Constellations align.
- Stations dock into view.
- Lights respond.
- Sounds evolve.

Reason:
A living observatory should feel like a place, not a collection of webpages.

# Decision 007 — Every Animation Must Have Meaning

Nothing animates because it "looks cool."

Every movement answers:

Why did it happen?

Examples:

Telescope rotates → because another constellation aligned.
Polaris glows → because he's speaking.
Lights brighten → because systems came online.
Stars move → because observation changed.

Never animate just because CSS can.

# Decision 008 — One Source of Attention

This is a UX principle.

At any moment, the observatory should guide the visitor to one primary thing.

For example:

Polaris speaks
↓

Everything else becomes quieter.

or

Research Station docks

↓

The telescope stops moving.

The visitor should never wonder where to look.

# Decision 009 — Motion Speed

The observatory is calm.

Nothing snaps.

Nothing flies.

Everything feels deliberate.

Think:

Observatory
Space
Precision

Not:

Gaming website
Cyberpunk dashboard
Flashy portfolio

# Decision 010 — The Observatory Never Sleeps

Even if the visitor doesn't touch anything...

Something is always alive.

Examples:

tiny star twinkles
faint hologram flicker
slow breathing glow
distant moving nebula
console pulse

A living place is never perfectly still.
